# InterSub

Corporate English training studio site for InterSub (言际阁), founded by Lydia Zhu to coach Chinese professionals in workplace English. Features a bilingual English–Chinese toggle with negotiated server rendering, a four-step method walkthrough, solutions spanning 1:1 coaching, team workshops, and co-created events, outcome case-study cards, a rotating testimonials carousel, an event catalog with timing, location, and level filters backed by content collections, per-event detail pages with markdown content and contact-prefill registration, a rate-limited contact form emailing through Resend, WeChat and podcast links, custom 404 and 500 pages, and a React admin dashboard behind Netlify Identity with event, outcome, and testimonial CRUD persisted to Netlify Blobs and mirrored to local JSON in dev. Built with Astro, React, TypeScript, Tailwind CSS, and GSAP. Deployed on Netlify.
